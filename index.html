Auto-reconnect
XAUUSD streams from Deriv's public gateway (no API key/token needed) with automatic failover to two legacy mirrors and a stale-feed watchdog, so a dead gateway or a silent, frozen candle build-up gets detected and reconnected on its own rather than requiring a manual refresh.
Broker / Execution
Trading account ● not connected
This build only streams live market data — it does not place trades. Live execution requires you to connect a broker account explicitly; credentials are never stored in the frontend or embedded in this file. Until connected, the app honestly reports SIMULATION / DISCONNECTED rather than pretending trades are happening.
